Sistema Web Torneo de Pelea eSport
Se enfocara en el registro de usuarios y confirmacion de asistencia al momento de las batallas, siguiendo las reglas de los eSports se usaran llaves aleateroas para designar a los integrantes que lucharan entre si, de esta manera se usaran los microservicios requeridos por el sistema:
Python/FastAPI: Para el registro de jugadores y en la modadlidad de equipos
Node.js Express: Para el historial de partidas y estadisticas de los mismos integrantes, como los personajes usado, daño infligido/recibido, duracion de la pelea
Java Spring Boot: Para las generacion de las llaves aleatorias, verificando quien peleara contra quien
Go Gin/net-http: El marcador en tiempo real

Web App eSport Fight Tourtament
To complete all requirements, we are going to create this web application for an online e-sports tournament, where the microservices are going to be:
Python/FastAPI: Login/Register of teams and solo players
Node.js Express: For the record of fights, statistics like characters, damage inflicted, and duration of these 
Java Spring Boot: To generate brackets for the random fights
Go Gin/net-http: Real time scoreboard

Utilizamos feature/mi-rama para agregar contenido, asi como los commit types: chore, docs, test, build...
Recuerda usar pip install -r requirements.txt en servicio-python para tener las mismas versiones de lo que instalamos
